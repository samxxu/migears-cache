# G3 — The logger is optional and silence is the default: …

## Finding / 问题

- EN: The logger is optional and silence is the default: `ArrayCache::__construct(?LoggerInterface $logger = null)` accepts null and stores it, and `RedisCache` accepts a null logger as well, so a cache that is handed no logger reports nothing while looking healthy. The logger must be passed in through the constructor and required, so that a call site which forgets it fails at assembly time rather than being silent at runtime.
- 中文: logger 是可选的，而默认就是静默：`ArrayCache::__construct(?LoggerInterface $logger = null)` 接受 null 并把它存下来，`RedisCache` 同样接受 null logger。于是一个没有拿到 logger 的 cache 看起来一切正常，却什么都不上报。logger 应当由构造函数明确传入且为必填，这样忘记传的调用点会在装配时就失败，而不是在运行时保持沉默。
- Where / 位置: `src/ArrayCache.php:24 · src/RedisCache.php:63-67`
- Verification / 验证: static / 仅静态
